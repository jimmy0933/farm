# 寶可夢對決：野外場景美化實作稿

## 目標
面向 4 歲幼兒，以五種色彩豐富、分層細緻的野外場景取代原先的白底對決。所有場景離線即可運行，保留大型招式按鈕、中文語音及設定中的中英按鈕切換。

## 五種野外場景

| 場景 | 內容 | 對手屬性 |
| --- | --- | --- |
| ☀️ 晴天草原（meadow） | 漸層天空、陽光、浮雲、丘陵、草叢、小花、遠近樹木 | 一般、電、超能力等 |
| 🌲 森林草地（forest） | 層疊樹冠、森林陰影、灌木、花朵 | 草、蟲 |
| 💧 湖邊水岸（lakeside） | 山峰、波光湖面、水紋、湖岸樹木、岩石 | 水、冰 |
| 🌅 黃昏原野（sunset） | 暖紫橘天空、夕陽、朦朧遠山、暖色草地 | 火 |
| 🌙 神秘夜林（moonforest） | 明月、星空、深紫藍樹木、螢光草地 | 幽靈、惡 |

背景選擇由 PokemonBattleScenery.gd 的 choose_biome 根據電腦對手屬性自動判斷；每場還有三種小幅配置變化。程式直接在 Godot 的 Control CanvasItem 中繪製，無需連網下載背景。

## 畫面配置

- 上方：雙方姓名、屬性、❤️ HP/100 血條卡，中央 ⚔️。柔和色塊與細緻陰影讓文字清楚。
- 中央：全景舞台、前景我方角色（左下，較大）、遠景電腦對手（右上，較小），各有圓形站位陰影；前方綠草、花朵及石頭增添景深。
- 招式影像覆蓋在景物上方，但不會攔截觸控操作。
- 下方：半透明風格的戰鬥訊息、兩個大招式按鈕、回圖鑑；勝負後顯示再戰一次及更換對手。
- 頂部導航和底部語音列固定在手機螢幕內，僅中央較長內容獨立捲動。

## 招式視覺

| 屬性 | 特效 |
| --- | --- |
| 電 ⚡ | 白金色閃電、金黃火花 |
| 火 🔥 | 橙紅火花、柔和光粒 |
| 水／冰 💧❄️ | 半透明水珠、水波紋 |
| 草／蟲 🌿🐛 | 飛葉、綠色柔光 |
| 幽靈／毒／超能力／惡 👻🔮 | 紫色能量球、環形光圈 |
| 其他 ⭐ | 星芒與圓形光環 |

每次攻擊約 0.77 秒，傷害數字彈出後淡出；剋制使用 🌟，免疫使用 🛡️。避免頻閃與激烈震動，符合幼兒遊玩需求。

## 遊戲規則不變
雙方 HP 100。一般攻擊隨機 12～20 基礎傷害，強力攻擊 20～30、隔一回合可再用；弱點／抵抗／免疫影響結果。電腦自動還擊，先歸零的一方輸。保留 12 隻可選角色、中文語音、中英切換和本機勝場紀錄。

## 對應實作與驗收

- scripts/PokemonBattleScenery.gd：五種場景與緩慢背景動畫
- scripts/PokemonBattleArena.gd：角色遠近站位、舞台及背景組合
- scripts/PokemonBattleEffects.gd：屬性特效與浮動傷害數字
- scripts/PokemonBattle.gd：血條卡、對戰訊息、招式控制、場景與回合規則整合
- tests/battle_scenery_smoke.gd：選景、站位、技能粒子及 1280×720／1024×600 版面
- tests/battle_smoke.gd：傷害、回合、勝負、英文按鈕、語音與底部跑版

CI 確認通過後，以原本的 GitHub Actions keystore 簽署 APK，發布最新版本，成功後才清理舊版。
